# FOX GENESIS

**Зміни себе. Вирости свій вид. Переживи зміну світу.**

Локальна браузерна гра в екосистемі FOX (`sites/fox-genesis/`). Офлайн, без npm і CDN.

## Запуск

1. У Ghostty: `sites` → Playground → **FOX GENESIS**
2. Або Hub → картка FOX GENESIS
3. Або відкрий `sites/fox-genesis/index.html` у Firefox / Zen / Chromium

Працює з `file://` (classic scripts, без ES modules).

## Керування

| Клавіша | Дія |
|---------|-----|
| WASD | Рух |
| Миша | Погляд / приціл |
| ЛКМ | Базова атака (укус / щелепи) |
| ПКМ | Здібність атакуючого органа |
| Q / E | Інші здібності встановлених органів |
| Shift | Ривок (потрібні ривкові лапи) |
| F | Збір, порятунок, здача вантажу в гнізді |
| M | Еволюція (перебудова тіла — лише в гнізді) |
| C | Колонія: будівлі, породи, накази, покоління |
| Tab | Карта |
| H | Довідка |
| Пробіл | Тактична пауза |
| Esc | Меню / скасувати будівництво |
| Колесо | Масштаб камери |

## Що є в грі

- Seed-світ із 5 біомами (ліс, болота, нагір’я, корені, водойми), туманом війни
- 24+ органи з реальною поведінкою та 8 синергіями
- Редактор тіла в гнізді, спеціалізації на рівні 2
- Колонія: серце, будівлі, породи, інкубація, накази союзникам
- Вороги-архетипи, боси біомів, директор подій
- Смерть без повного wipe: гени/колонія лишаються; відродження / союзник
- Нове покоління з різними базовими формами
- Автозбереження + експорт/імпорт JSON + резервна копія
- Якість Low/Medium/High, mute, reduced motion

## Збереження

- Ключі: `fox_genesis_save_v1`, резерв `fox_genesis_save_bak_v1`
- Автозбереження ~кожні 20 с, при новій грі, після імпорту
- Якщо `localStorage` недоступний під `file://` — гра працює, використовуй **Експорт** у меню
