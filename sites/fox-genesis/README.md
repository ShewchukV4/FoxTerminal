# FOX GENESIS

**Зміни себе. Вирости свій вид. Переживи зміну світу.**

Локальна браузерна гра в екосистемі FOX (`sites/fox-genesis/`). Офлайн, без npm і CDN. Версія **1.1**.

## Запуск

1. У Ghostty: `sites` → Playground → **FOX GENESIS**
2. Або Hub → картка FOX GENESIS
3. Або відкрий `sites/fox-genesis/index.html` у Firefox / Zen / Chromium

Працює з `file://` (classic scripts, без ES modules).

## Лікування (з перших хвилин)

1. **Біля серця гнізда** — стій поза боєм у світлому колі → повільний відпочинок (видно стан біля здібностей).
2. **R** — польове: «Відновити 20 HP · 3 біомаси» (спочатку з вантажу, потім із запасу колонії).
3. **Орган regen / камера** — сильніші варіанти пізніше.

Кнопка **Лікування** біля HP показує доступність і причину блокування.

## Прогрес

Панель «Наступний крок» підказує збір → лікування → гніздо → перший орган → здібність → шлях (Мисливець / Вартовий / Колонія) → союзник → особливе місце.

## Збереження

- Схема v2; міграція зі старих сейвів
- Primary + backup; пошкоджений primary не блокує валідний backup
- Порожній список ворогів — валідний стан (союзники не зникають)
- «Продовжити» **не** створює нову гру при помилці — показує причину

## Перевірки логіки

## Обмеження (чесно)

- Тунельний вузол прихований (stub) — не продається як порожня будівля
- «Велика зміна» ще не фінальний сценарій — пізня мета через покоління/босів
- Візуальна перевірка в браузері залежить від машини гравця; логічні регресії покриті тестами вище
