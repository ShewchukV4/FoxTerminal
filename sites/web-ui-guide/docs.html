01 / HTML

HTML: структура, зміст і семантика

HTML відповідає не за красу, а за сенс. Якщо структура правильна, CSS і JS підключати набагато легше.

Базова сторінка

Мінімальна сторінка має doctype, мову, charset, viewport, title, CSS і основний контент у body.

  • <!DOCTYPE html> вмикає сучасний режим браузера.
  • lang="uk" допомагає перекладачам, screen reader і пошуку.
  • viewport потрібен для нормальної мобільної адаптації.
  • title видно у вкладці браузера.
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Мій сайт</title>
  <link rel="stylesheet" href="./style.css">
</head>
<body>
  <main>Контент сторінки</main>
</body>
</html>

Семантичні теги

Семантика означає, що тег описує роль контенту. Це краще, ніж все робити через div.

  • <header> - верх сторінки або секції.
  • <nav> - головна навігація.
  • <main> - унікальний основний контент сторінки.
  • <section> - великий тематичний блок.
  • <article> - самостійна картка, пост, новина, товар.
  • <footer> - низ сторінки або секції.

Правильні кнопки і посилання

Якщо елемент переходить на іншу сторінку - це a. Якщо виконує дію на цій сторінці - це button.

  • <a href="./docs.html"> - перехід.
  • <button type="button"> - дія.
  • Не роби div-кнопки, якщо можна використати справжній button.

Форми

У кожного input має бути label. Placeholder не замінює label, бо він зникає під час вводу.

  • label пояснює поле.
  • name потрібен для відправки форми.
  • required вмикає просту браузерну перевірку.
  • type="email", type="password", type="search" дають правильну клавіатуру на телефоні.
<form class="contact-form">
  <label>
    <span>Email</span>
    <input name="email" type="email" required>
  </label>

  <label>
    <span>Повідомлення</span>
    <textarea name="message" rows="5"></textarea>
  </label>

  <button type="submit">Надіслати</button>
</form>

02 / CSS

CSS: стиль, layout, адаптивність і анімація

CSS краще будувати від системи: змінні, базові класи, layout, компоненти, states.

CSS-змінні

Змінні дають швидко змінювати тему сайту. Кольори, радіуси, тіні і відступи краще тримати в :root.

  • --bg - фон.
  • --text - основний текст.
  • --accent - головний акцент.
  • --radius - стандартне округлення.
:root {
  --bg: #080b13;
  --panel: rgba(18, 25, 43, .76);
  --text: #f6f7ff;
  --muted: #aab4cf;
  --accent: #7c5cff;
  --radius: 24px;
}

Grid vs Flex

Flex зручний для одного ряду або колонки. Grid краще підходить для сіток, карток, layout сторінки.

  • display: flex - кнопки, nav, chips, toolbar.
  • display: grid - галереї, dashboard, сторінкові макети.
  • gap краще, ніж margin між дітьми.
  • minmax(0, 1fr) допомагає уникати переповнення.
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 18px;
}

.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 12px;
}

Hover, focus, active

Інтерактивний елемент має реагувати. Hover - для мишки, focus - для клавіатури, active - під час натискання.

  • :hover показує, що елемент живий.
  • :focus-visible важливий для доступності.
  • :active дає відчуття кліку.
  • transition робить зміну плавною.
.button {
  transition: transform .2s ease, box-shadow .2s ease;
}
.button:hover {
  transform: translateY(-3px);
}
.button:focus-visible {
  outline: 3px solid #24d6c8;
  outline-offset: 4px;
}
.button:active {
  transform: translateY(1px);
}

03 / JavaScript

JS: поведінка, DOM і компоненти

JavaScript оживляє сторінку: tabs, sliders, modals, copy buttons, themes, cursor effects.

Пошук елементів

Найчастіше використовуються querySelector і querySelectorAll. Перший повертає один елемент, другий - список.

  • document.querySelector(".btn") - перший збіг.
  • document.querySelectorAll(".tab") - всі збіги.
  • closest() шукає батьківський елемент.
  • dataset читає data-атрибути.
const buttons = document.querySelectorAll("[data-tab]");

buttons.forEach((button) => {
  button.addEventListener("click", () => {
    console.log(button.dataset.tab);
  });
});

Класи як стан

Не міняй стилі напряму в JS без потреби. Часто краще додавати клас, а вигляд описувати в CSS.

  • classList.add додає клас.
  • classList.remove прибирає клас.
  • classList.toggle перемикає клас.
  • classList.contains перевіряє клас.
const modal = document.querySelector(".modal");
const openButton = document.querySelector("[data-open-modal]");
const closeButton = document.querySelector("[data-close-modal]");

openButton.addEventListener("click", () => modal.classList.add("show"));
closeButton.addEventListener("click", () => modal.classList.remove("show"));

LocalStorage

LocalStorage зберігає дані в браузері. Добре підходить для теми, налаштувань, маленьких локальних станів.

  • localStorage.setItem("theme", "dark") записує.
  • localStorage.getItem("theme") читає.
  • Зберігай прості строки або JSON.
const savedTheme = localStorage.getItem("theme");
if (savedTheme) {
  document.body.dataset.theme = savedTheme;
}

function setTheme(theme) {
  document.body.dataset.theme = theme;
  localStorage.setItem("theme", theme);
}

04 / accessibility

Доступність: щоб сайтом було реально користуватися

Доступність - це не тільки для screen reader. Це ще клавіатура, контраст, focus, зрозумілі labels і нормальні кнопки.

Контраст

Текст має читатися на фоні. Не став світло-сірий текст на білий фон або темно-сірий на чорний.

Focus

Користувач клавіатури має бачити, де він зараз. Не прибирай outline без заміни.

Alt

Зображення, які несуть зміст, мають мати описовий alt. Декоративні можуть мати порожній alt.

ARIA

ARIA допомагає, але не замінює правильний HTML. Спочатку використовуй семантичні теги.

05 / responsive

Адаптивність

Сайт має нормально виглядати на телефоні, планшеті і великому моніторі.

Mobile-first підхід

Спочатку зроби просту мобільну версію, потім додавай ширші layout через media queries.

  • Не став фіксовану ширину для всього.
  • Використовуй max-width і width: min(...).
  • Картинки роби max-width: 100%.
  • Для сіток використовуй auto-fit.
.page {
  width: min(1180px, calc(100% - 32px));
  margin: 0 auto;
}

@media (max-width: 700px) {
  .cards {
    grid-template-columns: 1fr;
  }
}
