02 / cursor recipes

Приклади курсорів з кодом

Glow follower

<div class="cursor-glow"></div>

.cursor-glow {
  position: fixed;
  width: 320px;
  height: 320px;
  border-radius: 50%;
  pointer-events: none;
  background: radial-gradient(circle, rgba(124,92,255,.22), transparent 68%);
}

Ring cursor

body[data-cursor="ring"] .cursor-glow {
  width: 56px;
  height: 56px;
  border: 2px solid #24d6c8;
  background: transparent;
  mix-blend-mode: difference;
}

Trail dots

window.addEventListener("pointermove", (event) => {
  const dot = document.createElement("span");
  dot.className = "trail-dot";
  dot.style.left = `${event.clientX}px`;
  dot.style.top = `${event.clientY}px`;
  document.body.appendChild(dot);
  setTimeout(() => dot.remove(), 700);
});

Spotlight

body[data-cursor="spotlight"] .cursor-glow {
  width: 460px;
  height: 460px;
  background: radial-gradient(circle, rgba(255,255,255,.16), transparent 58%);
  mix-blend-mode: screen;
}

03 / tips

Правила для кастомного курсора

Не перекривай кліки

У курсора обов'язково має бути pointer-events: none, інакше він буде блокувати кнопки.

Не роби занадто важко

Trail може створювати багато елементів. Видаляй їх через timeout або використовуй canvas.

Не ховай системний курсор всюди

Для docs і форм краще залишати нормальний курсор або робити дуже легкий ефект.

Поважай reduced motion

Для людей, яким важко від анімацій, можна вимкнути cursor trail через media query.
