Placeholders

Заглушки на той випадок, коли контенту ще немає.

Skeleton screens, empty states, error states, image stubs, lorem cards, спінери, бан-блоки, "soon", "404", "no results". Усе з прикладами коду, які можна копіювати.

01 / skeleton

Skeleton screens

Показуй приблизну форму контенту, поки дані ще завантажуються. Так сторінка не "стрибає" і виглядає швидшою.

<div class="skeleton-card">
  <div class="skeleton-row"></div>
  <div class="skeleton-row short"></div>
  <div class="skeleton-row mid"></div>
</div>

  border-radius: 999px;
  background: linear-gradient(90deg, #1c2336, #2c3550, #1c2336);
  background-size: 220%;
  animation: loading 1.2s infinite;
}
.skeleton-list {
  display: grid;
  grid-template-columns: 56px 1fr;
  gap: 14px;
  align-items: center;
}
.skeleton-avatar {
  width: 56px;
  height: 56px;
  border-radius: 50%;
  background: #1c2336;

}
.skeleton-image {
  width: 100%;

}

02 / empty states

Empty states

Коли немає даних, не лишай порожньо. Скажи людині, що сталось і що зробити далі.

!

Тут поки порожньо

Додай перший проєкт, щоб побачити список.

<div class="empty-state">
  <div class="empty-icon">!</div>
  <h3>Тут поки порожньо</h3>
  <p>Додай перший проєкт.</p>
  <button>Створити</button>
</div>
?

Нічого не знайшли

Спробуй інше слово або очисти фільтри.

.empty-icon {
  display: grid;
  width: 64px;
  height: 64px;
  place-items: center;
  border-radius: 50%;
  background: rgba(36,214,200,.16);
  font-size: 1.6rem;
  font-weight: 900;
}
⏳

Скоро з'явиться

Цей розділ ще в розробці.

.empty-state.soon .empty-icon {
  background: rgba(255,186,74,.16);
  color: #ffba4a;
}
⌧

Немає інтернету

Перевір з'єднання і спробуй ще раз.

.empty-state.offline .empty-icon {
  background: rgba(255,77,109,.16);
  color: #ff4d6d;
}

03 / errors

Сторінки і блоки помилок

404, 500, banned, no access. Завжди давай користувачу шлях назад.

404

Сторінку не знайдено

Адреса змінилась або була видалена.

<div class="error-stub">
  <span class="error-code">404</span>
  <h3>Не знайдено</h3>
</div>

.error-code {
  font-size: 4rem;
  font-weight: 900;
  background: linear-gradient(135deg, #ff4d6d, #ffba4a);
  -webkit-background-clip: text;
  color: transparent;
}
500

Сервер не відповідає

Ми вже працюємо над цим.

.error-stub.server .error-code {
  background: linear-gradient(135deg, #7c5cff, #24d6c8);
  -webkit-background-clip: text;
  color: transparent;
}
403

Доступ заборонений

Увійди в інший акаунт або попроси доступ.

.error-stub {
  display: grid;
  text-align: center;
  gap: 6px;
}
Помилка

Щось пішло не так. Спробуй ще раз.

.alert-stub {
  border-left: 4px solid #ff4d6d;
  border-radius: 14px;
  padding: 14px 16px;
  background: rgba(255,77,109,.12);
}

05 / lorem

Текстові заглушки

Готові короткі тексти, щоб бачити, як виглядає блок з реальним наповненням.

Lorem заголовок

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Тут буде нормальний опис продукту або статті.

<article class="lorem-block">
  <h3>Lorem заголовок</h3>
  <p>Lorem ipsum dolor sit amet, consectetur adipiscing elit.</p>
</article>

Заголовок українською

Тут має бути коротка історія користувача. Поки текст-заглушка, бо контент ще пишеться.

<article class="lorem-block">
  <h3>Заголовок українською</h3>
  <p>Тут має бути історія користувача.</p>
</article>
Категорія · 3 хв

06 / stubs

Сторінкові заглушки і ще трохи

Maintenance, coming soon, beta access, paywall, login wall.

0001

Технічні роботи

Сайт буде доступний через ~30 хвилин.

.page-stub {
  display: grid;
  gap: 8px;
  text-align: center;
  border-radius: 22px;
  padding: 30px;
}
.page-stub.maintenance {
  background: rgba(255,186,74,.12);
}
SOON

Готуємо новий розділ

Підпишись, щоб отримати інвайт.

.page-stub.coming {
  background: rgba(124,92,255,.16);
}
BETA

Закритий доступ

Введи інвайт-код, щоб увійти.

.page-stub.beta {
  background: rgba(36,214,200,.14);
}

Текст статті, який бачить користувач без підписки. Через декілька рядків текст плавно зникає...

.paywall-shadow {
  position: relative;
  max-height: 90px;
  overflow: hidden;
  mask-image: linear-gradient(180deg, black 30%, transparent);
}

07 / правила

Як писати тексти заглушок

Скажи, що сталось

Не залишай користувача в порожнечі. Поясни просто й без техмови.

Дай дію

Кнопка "Створити", "Повторити", "Перевірити інтернет". Без неї заглушка глуха.

Не лякай

"Помилка системи №54f-7" - погано. "Щось пішло не так, спробуй ще раз" - значно краще.

Тримай тон

Якщо сайт грайливий, не пиши строго. Якщо корпоративний - не жартуй.
