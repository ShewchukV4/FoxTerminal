# FOX SERPENT: EVOLUTION

Клітинкова змійка FOX. **1.4.0** — склад їжі на базі, грядки на сухій землі, процедурний арт, розумніші вороги/союзники.

**На змійці:** пожива 0–9 = довжина 3–12.  
**На базі:** окремий склад їжі (старт 12, +larder / талант «Склад I»). F біля гнізда або комори.

Їжа росте лише на **грядках** (старт: 4). Грядку можна ставити на **будь-якій вільній сухій землі**. Деревина — окремо.

## Запуск

Hub → Playground → **FOX SERPENT: EVOLUTION** або `sites/serpent-evolution/index.html`

## Склад їжі (F)

- Скласти / Взяти — прев’ю до кліку. Перекладання **без XP**.
- Скласти → хвіст коротшає. Взяти → ріст на наступних кроках.
- Носій доставляє в **склад бази**, не в гаманець гравця. Повний склад → чекає.

## B — будівництво курсором

- **B** — палітра; змія стоїть; вороги йдуть (поки немає Space-паузи). Esc/B — вихід. **R** — поворот.
- ЛКМ — поставити; **ПКМ** — скасувати розміщення; **X** — режим знесення.
- Drag паркану — **увесь ряд або нічого** (ціна й причина відмови в preview).
- Місткість деревини/їжі — **похідна** (база + склади + таланти). Знесення shed/larder заборонене, якщо запас перевищить новий cap.

## Вороги й союзники

- **Злодій** — бере один фізичний плід і тікає з видимим вантажем.
- **Розвідник** — обходить базу, запам’ятовує відкриті ворота; після повернення — «Базу помітили».
- **Дорослий** — може пошкодити огорожу з сусідньої клітинки (не входить у стіну).
- Союзники: садівник, носій → склад, ремонтник, сторож, розвідник.

## Гайд

Кожна сцена малює **видиму сітку** (`drawGuideBoard`) + фінальні sprites. H — гайд / легенда.
