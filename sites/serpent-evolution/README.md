# FOX SERPENT: EVOLUTION

Клітинкова змійка в екосистемі FOX. **Окрема гра** від Serpent Fox (`sites/snake/`) і FOX Genesis.

**Відпусти клавішу — зупинишся. Вороги продовжують рухатися.**

## Запуск

- Hub / `sites` → Playground → **FOX SERPENT: EVOLUTION**
- Або `sites/serpent-evolution/index.html` (file:// ок)

## Керування

| Клавіша | Дія |
|---------|-----|
| WASD / стрілки | Крок (tap = 1, hold = темп гри) |
| Відпустити | Повна зупинка |
| F / G / C | Навички з дерева (якщо обрані) |
| T | Дерево талантів |
| Tab | Карта / відкриття територій |
| Пробіл | Пауза всього світу |
| Esc | Меню |

## Зіткнення

- Голова → стіна / межа / власне тіло / інша змія = смерть голови
- Стоїш, ворог врізається в **тіло** (не голову) → гине ворог
- Зіткнення голів / swap клітинок → обидві гинуть
- Немає смужки HP: лише **одноразові серця** з дерева

## Серця

Кожне серце рятує **один** смертельний удар і зникає назавжди. Не регенерує після смерті чи reload. На розвилках дерева: **сильний талант A** або **+1 серце B** (взаємовиключно).

## Прогрес

- **Їжа** — довжина + досвід
- **Очки талантів** — дерево (~24 вузли, 6 розвилок)
- **Матеріал** — вантаж → гніздо → відкриття сусідніх chunks

Старт: 12×12 без ворогів. Вороги з’являються лише після **явного** відкриття небезпечної території.
