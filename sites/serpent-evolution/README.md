# FOX SERPENT: EVOLUTION

Клітинкова змійка FOX. **1.3.0** — бази, деревина, B-будівництво курсором, спокійне поле.

**Пожива 0–9 = довжина 3–12.** Їжа лише на **грядках** (старт: 4). **Деревина** — окремо.

## Запуск

Hub → Playground → **FOX SERPENT: EVOLUTION** або `sites/serpent-evolution/index.html`

## Tab — територія

- Ціна = `getExpansionQuote` = списання поживи.
- Підтвердження **в панелі** (не `window.confirm`). Помилки показуються в панелі.
- Збій генерації → повний rollback (tiles/chunks/вороги/пожива).

## B — будівництво курсором

- **B** — палітра; змія стоїть; вороги йдуть. Esc/B — вихід. **R** — поворот.
- ЛКМ — поставити **будь-де** на відкритій карті; **ПКМ / X** — знести (−50% деревини).
- Drag — ряд паркану. На паузі можна планувати; ставити — після зняття паузи.
- Shift+B або меню → база/союзники (найм, команди).

Гілки на землі / пень (**F**) дають деревину. Старт ≈ 4 деревини + вузли біля гнізда.

## Захист і рейди

Паркан/зачинені ворота блокують ворогів; свої проходять ворота. Незахищена зріла грядка може привабити змію, що її побачила. Чужі гнізда — на небезпечніших територіях.

## Дерево талантів

4 колонки (керування / дім / огляд / тактика), без перекриття вузлів. «До доступних» центрує viewport.
