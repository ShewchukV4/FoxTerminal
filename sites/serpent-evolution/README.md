# FOX SERPENT: EVOLUTION

Клітинкова змійка FOX. **1.2.0** — процедурний світ, ферми, союзники.

**Пожива 0–9 = довжина 3–12.** Відпусти клавішу — зупинись. Вороги рухаються самі.

## Запуск

Hub → Playground → **FOX SERPENT: EVOLUTION** або `sites/serpent-evolution/index.html`

На екрані старту: **Seed** (випадковий / свій / копіювати).

## Земля

- Перше розширення ≈ **3 поживи**; ціна в UI = `getExpansionQuote` = списання.
- Tab → «Відкрити територію…» · кнопка disabled, якщо бракує коштів.
- Карта з seed + `generatorVersion`; різні seed — різна геометрія.

## Ферми й союзники (B)

| Дія | Ціна (орієнтовно) |
|-----|-------------------|
| Ягідна грядка | 3 |
| Плодовий сад | 5 |
| Розсадник | 4 |
| Домівка | 4 |
| Найм садівника/носія… | 3–4 |

Урожай — **фізичні плоди** на полі / майданчику біля гнізда. З’їж їх сам, щоб отримати поживу. Садівник збирає й носить до drop pad.

Команди союзника: work / home / follow / wait.

## Клітинки

Луг, родючий/звичайний ґрунт, стежка, багнюка, мілководдя, глибока вода, камінь, зарості, міст, грядка, вхід домівки.
