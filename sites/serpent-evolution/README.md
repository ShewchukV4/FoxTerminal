# FOX SERPENT: EVOLUTION

Клітинкова змійка FOX. **1.6.0** — окремі світи печер (без втрати поверхні в сейві), багаття як будівля, крафт, 4 спеціалізації, рейди без HP, копання.

## Запуск

`sites/serpent-evolution/index.html` або Hub → Playground.

## Швидко

1. Обери спеціалізацію → **B → Багаття** на кільці біля гнізда (старт: 3д + 2к).
2. Дім (R — двері) + склад їжі + грядка → F біля багаття → зелений чекліст → Запросити.
3. **Верстак** (B) → F → дошки з деревини; камінь збирай F на купах.
4. Нова земля (Tab) може дати **вхід у печеру** або **ворожий табір**.
5. Печера: F увійти/вийти. Save всередині зберігає поверхню окремо.
6. **Q** — замах списа (смерть лише в голову), **E** — коротке парирування.

## Керування

WASD · B будівництво · F взаємодія · Q удар · E парир · Tab земля · T таланти · H гайд · Пробіл пауза · X знести
