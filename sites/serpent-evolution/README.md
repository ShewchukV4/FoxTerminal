# FOX SERPENT: EVOLUTION

Клітинкова змійка FOX. **1.5.0** — багаття й день/ніч, оплата зі складу здалеку, печери, FOV, поселення союзників, фікси 1.4.

## Запуск

`sites/serpent-evolution/index.html` або Hub → Playground.

## Швидко

- **Багаття** (F біля центру) — стан поселення, запрошення союзника, доплата з змійки.
- **Склад** — покупки (Tab, найм) спочатку зі складу понад резерв, потім опційно з carried; довжина не змінюється при оплаті лише складом.
- **Грядка** — будь-яка суха вільна земля (2д + 1п). B → plot.
- **Печера** — вхід на нових територіях (F); обмежений огляд, вихід тим самим.
- **Союзник** — потрібен осередок: дім + багаття поруч + їжа + грядка + прохідні шляхи (чекліст у багатті).

## Керування

WASD · B будівництво · F взаємодія/склад/багаття/печера · Tab земля · T таланти · H гайд · Пробіл пауза · X знести

## Тести

`node tests/_run-node.js` або `tests/logic-tests.html`

## Обмеження 1.5

- Зграї з повною економікою/рейд-планувальником — частково (злодій/розвідник/elder є).
- Виробництва (піч/мідь/смола) і повне дерево талантів 5×8 — наступна хвиля.
- Браузерний візуальний прогін (день/ніч/печера/спрайти) — вручну після Ctrl+F5.
