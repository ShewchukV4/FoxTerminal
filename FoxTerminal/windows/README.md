```

і FoxTerminal/windows/VERIFY_ALL.md.
Відповідай українською.
Зніми залізо й монітори, піджени Fox,
потім прожени КОЖНУ команду і оболонку (Alt+Tab, таскбар, Win, dock).
Видай звіт PASS/FAIL. Не вмикай foxlook shell.
```
